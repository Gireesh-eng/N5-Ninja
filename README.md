# JLPT N5 Study Application

A comprehensive study platform for Japanese Language Proficiency Test (JLPT) N5 level preparation. This application helps learners master essential Japanese grammar, vocabulary, and language concepts required for the JLPT N5 certification.

## Features

- 📚 Comprehensive Grammar Lessons
- 📝 Vocabulary Practice with 800+ Essential Words
- 🎯 Interactive Study Sections
- 💫 Modern, Responsive Interface
- 🌙 Dark Mode Support

## Technologies Used

- Frontend Framework: React with TypeScript
- Build Tool: Vite
- Styling: Tailwind CSS
- UI Components: shadcn/ui
- State Management: React Context API
- Routing: React Router
- Deployment: Deployed on Firebase Hosting
- Custom Domain: n5-ninja.me (Live and accessible)


## Prerequisites

- Node.js (v18 or higher)
- npm (v9 or higher)

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/Gireesh-/n5-ninja-prep.git
cd n5-ninja-prep
```
2. Install dependencies:
```bash
npm install
```
